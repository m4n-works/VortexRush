# VORTEX RUSH

ネオンのトンネルを駆け抜ける3Dアーケードゲーム（Three.js / 単一HTML）。

▶ プレイ: https://m4n-works.github.io/VortexRush/

## 操作
- ← → / A D : トンネルを回転移動
- SPACE : オーバードライブ（ゲージMAX時）
- M : ミュート
- スマホ : 画面の左右をタッチ

## 遊び方
- クリスタルを連続で取ってコンボ倍率アップ
- 障害物をギリギリで避けると NEAR MISS ボーナス
- ゲージMAXでオーバードライブ：超加速＆障害物を粉砕
- 青いシールドは1回だけ衝突を防ぐ
